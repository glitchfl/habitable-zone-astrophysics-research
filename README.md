# Habitable zone sensitivity to albedo and greenhouse

A physics research project (עבודת גמר בפיזיקה) asking the question:

> when you change a planets albedo `A` and its effective greenhouse parameter `eps` how far do the
> habitable-zone boundaries `a_in` and `a_out` move around real stars and does that sensitivity
> depend on the type of star?

The stars are real - 3000 main-sequence rows pulled from Gaia DR3. The planet is a grey 0-D
energy-balance model so the whole thing collapses to two formulas:

```
T_p(a) = Teff * ((1-A)/(4 eps))^(1/4) * (R*/a)^(1/2)
a(T)   = R*   * ((1-A)/(4 eps))^(1/2) * (Teff/T)^2
```

Boundaries are `a(373.15 K)` and `a(273.15 K)` - the 1 atm liquid-water range.

## Layout

```
src/          the pipeline (one module per stage)
gaia/         query.adql + a VOTable -> csv converter for the archive download
csv/          the Gaia DR3 sample that data.py reads
results/      figures/, tables/ and summary_report.txt - all regenerated by main.py
docs/         theoretical background (Hebrew)
```

`src/` runs in order: [data.py](src/data.py) (read + quality cuts + derive `R*`) ->
[scenarios.py](src/scenarios.py) (the 3x3 grid of `A` x `eps`) ->
[boundaries.py](src/boundaries.py) (`a_in`/`a_out` for every star x scenario) ->
[sensitivity.py](src/sensitivity.py) (shifts against the Earth-like reference) ->
[analysis.py](src/analysis.py) (five separate tests of the `Teff` cancellation) ->
[report.py](src/report.py) + [figures.py](src/figures.py).

[model.py](src/model.py) holds the equations themselves and nothing else. Every cut, constant and
scenario level lives in [config.py](src/config.py).

## Running it

```sh
uv run src/main.py
```

Rewrites everything under `results/`

To refresh the star sample: run [gaia/query.adql](gaia/query.adql) at
https://gea.esac.esa.int/archive/ download the result then

```sh
uv run gaia/votable_to_csv.py <downloaded.vot>
```
